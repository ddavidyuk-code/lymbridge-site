# Lymbridge Logistics — сайт

Одностраничный сайт компании (UA / EN / PL), вариант дизайна «C — фирменный»: 3D-глобус с маршрутами, эффекты.

- Всё в одном файле `index.html` — без сборки и зависимостей.
- Публикация: GitHub Pages (ветка `main`, корень репозитория).
- Как обновить: заменить `index.html` → Commit to main → Push origin. Сайт обновится через 1–2 минуты.
- Форма «Запросить ставку» открывает почту и отправляет заявку на info@lymbridge.eu.
